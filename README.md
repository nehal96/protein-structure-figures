# Protein structure figures

The figures from *Solving the First Protein Structures* (newtinteractive.com).

```bash
npm install
npm run dev
```

Every figure is shown in essay order, one page per draft of the essay. The components are in `src/draft-3/` and `src/draft-4/`, and each draft keeps its own copies of the shared helpers. `src/site/` stands in for the parts of the main site they import.
